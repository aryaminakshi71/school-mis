## 🚀 DEPLOYMENT COMMANDS

### Web App Deployment
```bash
# Build
npm run build:web

# Deploy to Cloudflare
wrangler pages deploy apps/web/dist

# Or full deployment
npm run deploy
```

### API Deployment
```bash
# Build
npm run build:api

# Deploy to Cloudflare Workers
wrangler deploy

# Or full deployment
npm run deploy
```

### Mobile Apps
```bash
# iOS
cd apps/mobile
npm install
npm run ios
# OR: npx expo build:ios

# Android
cd apps/mobile
npm install
npm run android
# OR: npx expo build:android
```
